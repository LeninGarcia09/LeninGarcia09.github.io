# Weekly Tracker v4

This page is the plan's weekly tracking system.

## Quick status (badges)

- [GREEN] On track and with published evidence.
- [YELLOW] Moderate risk, requires weekly adjustment.
- [RED] High risk, activate immediate recovery.
- [PENDING] Week not yet closed.

## How we use it

- Update this table every Friday.
- Mark weekly status as: Green | Yellow | Red.
- Add at least 1 evidence link per week.
- If there are 2 consecutive red weeks, execute the recovery protocol from [Checkpoint Gates v4](./checkpoints).

## Status legend

- **Green:** Weekly objective achieved with published evidence.
- **Yellow:** Partial progress; there is delay risk.
- **Red:** Objective not met; recovery is required.

### Monthly close checklist

- Update Green/Yellow/Red count for the month.
- Confirm monthly gate status (green/yellow/red).
- Record executive decision: continue, adjust, or recover.
- Define next month's focus in one line.

## Weekly close checklist

- Update the week's status.
- Paste evidence links (repo, post, benchmark, demo).
- Record decision: continue, adjust, or recover.
- Plan the following week's objective.
