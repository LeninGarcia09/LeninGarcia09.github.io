# Fuentes y verificación

:::info[Por qué existe esta página]
Un plan de aprendizaje solo es confiable si sus recomendaciones son **reales, actuales e independientemente verificables**. Esta página documenta cada programa, certificación y marco referenciado en esta sección, con enlaces a **fuentes primarias** para que un lector, patrocinador, CEO o Junta pueda confirmarlos directamente.
:::

## Método de verificación

1. **Solo fuentes primarias** — páginas oficiales de proveedores (universidades, Microsoft, organismos de estándares), no blogs ni agregadores.
2. **Capturar la fecha "as of"** — las certificaciones cambian; registramos cuándo se verificó cada una.
3. **Separar hecho de recomendación** — existencia/alcance del programa es *hecho* verificable; secuencia y timing se etiquetan como *juicio*.
4. **Reverificar trimestralmente** — los programas ejecutivos y certificaciones de Microsoft se renombran o retiran regularmente.

**Última verificación:** 2026-07-18
