## Resumen del examen

- **Examen:** AZ-104 — *Microsoft Azure Administrator*
- **Certificación:** Microsoft Certified: Azure Administrator Associate
- **Nivel:** Associate (intermedio)
- **Rol:** Administrator
- **Puntaje aprobatorio:** 700 / 1000
- **Renovación:** anual (gratuita)
- **Costo:** el precio varía según el país o la región (~$165 USD en EE. UU.)

## Por qué este examen importa para arquitectos de IA

AZ-104 es la base de infraestructura y el **prerrequisito para AZ-305 Expert**. Las cargas de trabajo de IA necesitan aislamiento de red (VNet, NSG, private endpoints), almacenamiento (ADLS Gen2, Key Vault) e identidad/cómputo (managed identities, RBAC), todos temas de AZ-104. No puedes diseñar soluciones de IA seguras sin entender la capa de infraestructura.

## Habilidades evaluadas (áreas verificadas)

Según la guía oficial de estudio, AZ-104 evalúa estas áreas. Las ponderaciones cambian entre versiones; **[la guía oficial de estudio](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-104/) es la fuente de verdad**:

- Administrar **identidades y gobernanza de Azure**
- Implementar y administrar **almacenamiento**
- Implementar y administrar recursos de **Azure compute**
- Implementar y administrar **redes virtuales**
- **Supervisar y mantener** recursos de Azure

## Cómo estudiar (enfoque basado en ciencia del aprendizaje)

1. **Diagnostica primero** con la evaluación práctica oficial.
2. **Haz los laboratorios.** AZ-104 es práctico: ejercítate en Azure portal, CLI, PowerShell y Bicep. Usa una cuenta gratuita de Azure.
3. **Recuperación activa + espaciado.** Reconstruye cada flujo de trabajo administrativo desde la memoria y repásalo a lo largo de varios días (Dunlosky et al., 2013).
4. **Enséñalo de vuelta** con una guía operativa breve por dominio.
5. **Vuelve a evaluarte hasta superar el 80%** antes de agendar.
