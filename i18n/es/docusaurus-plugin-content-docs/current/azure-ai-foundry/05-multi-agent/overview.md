# Orquestación Multi-Agent

:::info[Próximamente]
Esta sección cubrirá la coordinación de múltiples agentes especializados: patrones de traspaso, memoria compartida, límites de seguridad y arquitecturas multi-agent a escala empresarial.
:::

## Desafíos planificados

- **Traspaso de agente a agente** — delegación segura con Entra Agent ID
- **Gestión de contexto compartido** — estado conversacional entre límites de agentes
- **Patrones fan-out/fan-in** — agentes especialistas en paralelo con agregación de resultados
- **Aislamiento multi-tenant** — separación de cargas de trabajo de agentes por cliente
