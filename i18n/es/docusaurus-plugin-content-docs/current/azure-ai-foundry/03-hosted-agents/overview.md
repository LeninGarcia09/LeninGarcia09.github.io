# Hosted Agents

:::info[Próximamente]
Esta sección cubrirá la implementación y administración de Hosted Agents con control total del código, compatibilidad con frameworks BYO (LangGraph, Semantic Kernel), aislamiento con Micro-VM y Entra Agent ID.
:::

## Desafíos planificados

- **Implementación de agentes basada en contenedores** con runtimes personalizados
- **Optimización de arranque en frío** — lograr inicio en menos de 1 s
- **Patrones de escalado** — autoescalado, idle-to-zero, manejo de picos
- **Aislamiento de seguridad** — límites de Micro-VM, directivas de red
