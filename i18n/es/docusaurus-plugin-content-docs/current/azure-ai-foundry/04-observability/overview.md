# Observabilidad y evaluación

:::info[Próximamente]
Esta sección cubrirá la observabilidad de extremo a extremo para agentes de IA: trazas de OpenTelemetry, paneles de Azure Monitor, puntuación con el Evaluation SDK y patrones de monitoreo en producción.
:::

## Desafíos planificados

- **Trazado de flujos de trabajo de agentes** — spans de OpenTelemetry en ejecuciones de agentes de varios pasos
- **Pipelines de evaluación** — puntuación de groundedness, coherencia, fluidez y seguridad
- **Alertas sobre deriva** — detección de degradación de precisión en producción
- **Atribución de costos** — seguimiento de uso de tokens por agente y por tenant
